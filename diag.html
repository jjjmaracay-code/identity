4. Probar index.html

Abre index.html en una pestana nueva con un detector de errores de JavaScript activo desde antes de que se ejecute cualquier otro script de la pagina. Si ocurre un error, aparecera una franja amarilla en la parte de arriba de esa pestana nueva con el mensaje, el archivo y la linea.

Nota: se abre en una pestana nueva (no dentro de esta pagina) porque las cabeceras de seguridad del sitio contra clickjacking (X-Frame-Options / frame-ancestors) impiden insertar index.html en un iframe; esto evita tener que debilitar esa proteccion.

5. Desregistrar Service Worker y borrar SOLO las cachés

Esto NO borra ningun dato guardado (localStorage/sessionStorage). Solo desregistra el Service Worker y borra las cachés de archivos, para comprobar si el problema es el Service Worker.
